# Credits

## Art

All art is original and AI generated for this game. The heroes and monsters are pixel art placed pixel by pixel in code (`src/game/art/pixel/`), the backdrops and map scenery are paintings written as SVG in code (`src/game/art/paintings/`), the map's ground is painted on a canvas when a floor loads (`src/game/art/ground.js`), and the menus, logo and effects are drawn in code at startup. The game ships no image files of its own art.

`map/spritesheet.png` and `../favicon.png` are exports of the earlier pixel art. The spritesheet only exists so the map can still be edited in Tiled.
